# Bundled pet packs

This directory is included in desktop bundles. Each child directory is a
validated, original pet-pack with a `manifest.json`, transparent sprite assets,
and a preview image. The bundled catalog currently includes:

- `dev.opencoder.byte` — Moss Lantern
- `dev.opencoder.orbit` — Orbit Helper
- `dev.opencoder.shiba` — Blue Bandana Shiba
- `dev.opencoder.sunny-cat` — Sunny Cat

User-installed `.opet` archives are kept outside this directory and are never
allowed to claim the reserved `dev.opencoder.*` namespace.
