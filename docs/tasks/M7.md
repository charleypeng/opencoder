## 附录：TASK-M7-09 落地备注（2026-08-05）

**落地内容**

- **文件树移动版**（`src/features/files/FileTree.tsx` 新增 `variant?: "desktop" | "mobile"`）：移动形态为**单层目录浏览**——当前目录的 children 平铺渲染（整行 `min-h-11` 触控目标，无 hover/右键），点目录即进入（`navigateInto`：标记 expanded + 切换 currentPath + 子树未加载时经既有 `loadChildren` 拉取并嫁接进共享 store），点文件经 `onOpenFile` 打开；顶部**面包屑返回条**（`Workspace` 根 + 各路径段，祖先段可一键跳回，当前段为纯标签）；**右键菜单在移动形态不挂载**（长按菜单按规格留给 M8 菜单任务）；watcher 版本刷新后 expanded 目录自动 refill，currentPath 子树保持；空目录显示「Empty folder」。
- **查看器移动全屏 + 缩放**（`src/features/files/FileViewer.tsx`）：`fullscreen` prop 正式启用——移动页下滚动容器 `touch-action: pan-x pan-y`（双指平移、禁浏览器缩放劫持）、代码区**双击缩放切换 100%/150%**（CSS `transform: scale(1.5)` + `transform-origin: top left`，缩放产生滚动溢出域），tab 栏右侧有镜像状态 chip（100%/150%），**文件切换自动复位 100%**；规格中的真双指 pinch 按任务指引**以双击切换简化落地并文档化**（见遗留）。
- **文件 Tab 页面**（`src/shells/mobile/FilesPage.tsx` + `FileViewPage.tsx`）：FilesPage = 移动 FileTree + 点文件 `openTab`（复用 viewer store 原样）后 `push({ page: "file-view", params: { path } })`；FileViewPage = PageHeader（basename 标题 + Back）+ 全屏 FileViewer；`routeKey` 补 `path` 参数维度（file-view 连开不同文件各自重挂载）。

## 附录：TASK-M7-08 落地备注（2026-08-05）

**扫码后端选型（spike 结论）**：采用官方维护的 `tauri-plugin-barcode-scanner` 2.4.5（crates.io + npm `@tauri-apps/plugin-barcode-scanner` 同版本，plugins-workspace），**不手写** Swift/Kotlin 桥。证据：crate 源码含完整移动端实现（iOS AVFoundation、Android ML Kit）。**关键发现：Rust crate 以 `#![cfg(mobile)]` 声明**——桌面编译产物为空 crate（`init()` 在桌面目标不存在），因此 `src-tauri/src/lib.rs` 以 `#[cfg(mobile)] let builder = builder.plugin(...)` 守卫注册（桌面 cargo check 验证通过）；capabilities 授予 `barcode-scanner:default`（默认权限集含 allow-scan/cancel/check-permissions/request-permissions/open-app-settings/vibrate）。iOS 相机权限：`NSCameraUsageDescription` 已写入 `src-tauri/gen/apple/opencoder_iOS/Info.plist` **及其 XcodeGen 源 `project.yml`**（两者同步；`tauri ios init` 重生成不会动 project.yml，但会重建 Info.plist——重建后需按此备注补回）。Android 相机权限（`AndroidManifest.xml` 的 `CAMERA`）待 gen/android 脚手架生成后补（本机无 Android SDK，见 M7-01 附录）。

**落地内容**

- **扫码门面**（`src/services/scanner.ts`）：沿用 haptics 纪律——`canScan()`（Tauri `__TAURI_INTERNALS__` 存在 + `platform.kind === "mobile"` 双重判定，桌面端插件未注册、任何 invoke 必失败，拒绝发出）；`scanQrCode()` 一次性全屏扫码（`pluginScan({ formats: [Format.QRCode] })` → 解码文本；失败/取消向上抛错，由 UI 呈现）。
- **连接 URL 编解码**（`src/features/servers/qrConnect.ts`，纯函数）：`encodeConnectUrl` 生成 `opencode://connect?url=…&name=…`（URLSearchParams 自动编码；**只含 url+name，绝不编码凭据**；parse 侧容忍可选 `token`，encode 侧不产 token）；`parseConnectUrl` 严格逆运算——只接受 `opencode://connect` scheme+host，`url` 经 `normalizeServerUrl` 校验/规范化（无 scheme 的 `192.168.1.5:14096` 亦可），`name` 非空，缺失/非法返回 null。
- **移动端扫码入口**：AddServer 新增可选 `scanEnabled` prop（ServerHome 在 `platform.kind === "mobile"` 时传入；编辑模式 `props.server` 存在时按钮永不显示）；URL 输入框旁渲染「Scan QR」按钮 → `scanQrCode()` → `parseConnectUrl` → 预填 name+url → **自动触发探测**（规格：扫码→预填→探测→保存，探测失败用户可改后重试）；非连接码与相机失败均有内联错误文案。
- **桌面端二维码**：服务器卡片右键/菜单按钮菜单新增「Show QR code」项 → `ServerQrDialog.tsx`（Kobalte Dialog，沿用 ShareSessionDialog 的 QR/复制惯例）：只读 connect URL + 复制按钮（Clipboard API + execCommand 兜底、「Copied!」反馈）+ 160px 二维码 + 「二维码仅含 URL 与名称、绝不含凭据；扫码设备需能访问该服务器」提示。
- **测试（L1/L2）**：qrConnect 13 例（encode 载荷形状/不含凭据/往返、URL 解码、无 scheme 规范化、token 透传与空 token 丢弃、空白修剪、随机文本/异 scheme/异 host/缺字段/非法 url/空名拒绝）；scanner 6 例（canScan 三态、非 Tauri/桌面不调用插件、移动端调用参数、失败传播）；AddServer 6 例（按钮隐藏/可见门控（含非 Tauri 与编辑模式）、扫码预填+自动探测、非连接码拒绝且不探测、相机失败文案）；ServerHome 4 例（菜单→对话框 QR 图 + 载荷不含凭据、复制反馈、Esc 关闭、移动平台 AddServer 出现扫码按钮）。`pnpm verify` 8/8 通过。

- **安全区工具类**（`src/styles/index.css`）：`pt-safe`/`pb-safe`/`px-safe`/`pb-safe-bar`，均为「基础值 → constant()（iOS 11.0–11.2 命名）→ env(inset, 0px)」回退链，浏览器只采用最后一个受支持的声明；`pb-safe-bar` = `--safe-bar-h`（4.5rem，原生悬浮胶囊 bar 高）+ 底部 inset。类为无 layer 声明，与 Tailwind 的 py-/px- 冲突时以 max(base, env()) arbitrary 值组合（ServerHome header）。
- **原生 bar 可见性门控**（本轮修复 M7-03 review 的「首页出现带 inert tab 的原生栏」）：`GlassPlugin.swift` 默认创建隐藏 bar（`tabBarHidden` 状态兜底 web 与注入的竞态），新增 web → native `setHidden { hidden }` 消息；web 侧新增 `src/shells/mobile/glassControl.ts`（`setGlassBarShown`/`setGlassBarHidden`，无桥 no-op）：App 启动时（mobile）断言隐藏，MobileShell 挂载时显示、卸载时隐藏——ServerHome（应用落点）永不出现底部栏，工作区才有 4-tab。
- **iOS 26 edge effect**：`load()` 内 `if #available(iOS 26.0, *) { webview.scrollView.topEdgeEffect.isHidden = true }`（best-effort，编译期守卫；`topEdgeEffect` 为 iOS 26 SDK API）。
- **dvh 与安全区应用**：MobileShell 根 `h-screen` → `h-dvh`，原生模式内容 padding `pb-20` → `pb-safe-bar`，web 导航 `pb-[env(...)]` → `pb-safe`；ServerHome 根 `min-h-screen` → `min-h-dvh` + `pb-safe`，sticky header 顶部/左右 padding 以 `max(1rem/1.5rem, env(...))` 纳入刘海与横屏侧边 inset（桌面端 env()=0，零回归）；PromptBox 底部 padding 加 `max(0.75rem, env(safe-area-inset-bottom))`（键盘适配注释：resizes-content 后 shrink-0 组合框自然吸附键盘上沿）。
- **横屏**：`@media (orientation: landscape) { .landscape-terminal { height: 100dvh } }`，应用于 Terminal 占位页（机制先行，M7-09 细化真终端全屏）。
