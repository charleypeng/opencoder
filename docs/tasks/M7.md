## 附录：Liquid Glass Spike 结论（TASK-M7-02 填写）

- 验证环境：Xcode 26.0.1（Build 17A400）/ iOS SDK 26.0 / iPhone 17 模拟器（iOS 26.0），`tauri ios build --debug --target aarch64-sim --ci`
- 结论：☑ **通过（档位 A 启用）**（原生 UITabBar 注入 + 双向事件桥均验证成功）
- 验证证据（归档 `docs/spikes/m7-02/`：`glass-final.png` 截图 + `glass-demo.mov` 录屏）：
  1. **原生 tab bar 可见**：模拟器系统日志 `[glass] tab bar injected, 4 items`；截图 OCR（Vision）识别到底部原生栏 4 个 tab 文案（会话/文件/终端/设置，均匀分布 y≈0.036）
  2. **Liquid Glass 材质**：像素采样显示 tab 栏为**悬浮胶囊**（左右留边，x=0.01/0.99 处为页面背景色）且**半透明提亮**（栏区亮度 22–55 vs 页面背景 15，暗底内容透出）——非不透明整宽条；iOS 26 SDK 默认渲染 Liquid Glass 材质
  3. **web → native → web 事件往返**：demo 页 JS 向 `glassBridge` 发 `setActive(1/2)` → Swift 收到（日志 `message from web`）→ `tabSelected -> web: 1/2` → 前端计数更新（截图 OCR：`events: 2 · last tab: 2`）
  4. **native → web 直连**：`ping` → Swift `nativePing -> web: pong` → 前端显示 `ping: pong`（OCR 确认）
  5. iOS 构建链路：`pnpm verify` 8/8 通过
- 问题与 workaround：
  - **物理点按无法脚本化**（本机无 idb、无辅助功能权限，AppleScript 被拒 -1719）：`tabBar(_:didSelect:)` 委托路径通过程序化 `selectedItem` + 显式 `notifyTabSelected` 全链路验证（与真实点按走同一委托 → JS 回调路径）；真实手指点按留待 M7-03 L5 手动清单
  - **`tauri ios build` 二次构建报错** `failed to rename app ... Directory not empty`：archive 残留所致，`rm -rf src-tauri/gen/apple/build/opencoder_iOS.xcarchive` 后重跑即可（非代码问题）
  - **插件注册机制**：`tauri-plugin-glass`（path dep）经 build.rs `tauri_plugin::Builder::new(&[]).ios_path("ios")` 声明 Swift 源，`tauri ios build` 自动编译并链接进 `libapp.a`（`nm` 可见 `GlassPlugin` 符号）；iOS 侧注册走 `api.register_ios_plugin(init_plugin_glass)` + `@_cdecl`。`tauri ios init` 重生成 `gen/apple` **不会**覆盖 `src-tauri/plugins/glass`（正确扩展点）
  - **spike 无 Rust command**：桥接为 Swift + JS 直连（`evaluateJavaScript` / `WKScriptMessageHandler`），符合任务说明；`glass_set_tab_items/setActive/setHidden/set_badge` 契约随 M7-03 落地
  - 验证环境限制：无法读图，截图结论依赖 Vision OCR + 像素采样脚本（脚本归档于本机 /tmp，非仓库文件）
