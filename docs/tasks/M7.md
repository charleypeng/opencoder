## 附录：Liquid Glass Spike 结论（TASK-M7-02 填写）

- 验证环境：Xcode 26.0.1（Build 17A400）/ iOS SDK 26.0 / iPhone 17 模拟器（iOS 26.0），`tauri ios build --debug --target aarch64-sim --ci`
- 结论：☑ **通过（档位 A 启用）**（原生 UITabBar 注入 + 双向事件桥均验证成功）
- 验证证据（归档 `docs/spikes/m7-02/`：`glass-final.png` 截图 + `glass-demo.mov` 录屏）：
  1. **原生 tab bar 可见**：模拟器系统日志 `[glass] tab bar injected, 4 items`；截图 OCR（Vision）识别到底部原生栏 4 个 tab 文案（会话/文件/终端/设置，均匀分布 y≈0.036）
  2. **Liquid Glass 材质**：像素采样显示 tab 栏为**悬浮胶囊**（左右留边，x=0.01/0.99 处为页面背景色）且**半透明提亮**（栏区亮度 22–55 vs 页面背景 15，暗底内容透出）——非不透明整宽条；iOS 26 SDK 默认渲染 Liquid Glass 材质
  3. **web → native → web 事件往返**：demo 页 JS 向 `glassBridge` 发 `setActive(1/2)` → Swift 收到（日志 `message from web`）→ `tabSelected -> web: 1/2` → 前端计数更新（截图 OCR：`events: 2 · last tab: 2`）
  4. **native → web 直连**：`ping` → Swift `nativePing -> web: pong` → 前端显示 `ping: pong`（OCR 确认）
  5. iOS 构建链路：`pnpm verify` 8/8 通过
- 问题与 workaround：
  - **物理点按无法脚本化**（本机无 idb、无辅助功能权限，AppleScript 被拒 -1719）：`tabBar(_:didSelect:)` 委托路径通过程序化 `selectedItem` + 显式 `notifyTabSelected` 全链路验证（与真实点按走同一委托 → JS 回调路径）；真实手指点按留待 M7-03 L5 手动清单
  - **`tauri ios build` 二次构建报错** `failed to rename app ... Directory not empty`：archive 残留所致，`rm -rf src-tauri/gen/apple/build/opencoder_iOS.xcarchive` 后重跑即可（非代码问题）
  - **插件注册机制**：`tauri-plugin-glass`（path dep）经 build.rs `tauri_plugin::Builder::new(&[]).ios_path("ios")` 声明 Swift 源，`tauri ios build` 自动编译并链接进 `libapp.a`（`nm` 可见 `GlassPlugin` 符号）；iOS 侧注册走 `api.register_ios_plugin(init_plugin_glass)` + `@_cdecl`。`tauri ios init` 重生成 `gen/apple` **不会**覆盖 `src-tauri/plugins/glass`（正确扩展点）
  - **spike 无 Rust command**：桥接为 Swift + JS 直连（`evaluateJavaScript` / `WKScriptMessageHandler`），符合任务说明；`glass_set_tab_items/setActive/setHidden/set_badge` 契约随 M7-03 落地
  - 验证环境限制：无法读图，截图结论依赖 Vision OCR + 像素采样脚本（脚本归档于本机 /tmp，非仓库文件）

## 附录：TASK-M7-06 落地备注（2026-08-05）

**落地内容**

- **手势 hook 模块**（`src/shells/mobile/gestures.ts`）四个 hook，统一纪律：
  - **方向锁定**：手势移动 ~10px（`GESTURE_SLOP_PX`）前不表态；按主轴锁定后——横向手势接管指针、纵向立即放弃（交给滚动容器），因此左滑/长按/边缘右滑与滚动互不干扰；可滑动行 CSS `touch-action: pan-y`（浏览器原生纵向滚动，横向 pan 交给 JS）。
  - **窗口级监听 + 双路径拆除**：pointerdown 后 move/up/cancel 均挂在 window（Sheet 同款模式），up/cancel 与组件卸载都会移除监听。
  - **pointercancel 语义**（M7-05 遗留项补全）：浏览器抢走手势（滚动窃取/系统返回/双击缩放）时——swipe 行按提交阈值归位到最近状态（不翻转）、PTR 中止、长按/边缘滑动取消、Sheet 吸附到最近档位且**绝不关闭**。
  - **click 守卫**：手势位移超过 slop（或点按收起已露出行）后，元素上挂一次性 capture click 吞掉（500ms 自移除），防止手势结束的点击激活手指下方的按钮。
- **`useSwipeActions`**：横向拖拽露出操作条（默认宽 80px 可配；`SWIPE_COMMIT_PX=40` 提交阈值；右侧拖拽不会拉出、超出阈值才收起）；已露出行点按 = 收起 + 吞点击（不导航）；行状态由父组件互斥（SessionsPage 记录最近露出的行 id，其余行收起）。
- **`useLongPress`**：按住 `LONG_PRESS_MS=500` 触发回调（带按压坐标）；位移 >10px、pointerup、pointercancel、卸载均取消定时器；触发后释放点击被吞掉。
- **`usePullToRefresh`**：基于 **touch 事件**（唯一能 preventDefault 原生纵向滚动的通道；pointer 方案会因 touch-action 被 cancel）；仅容器 `scrollTop===0` 时跟踪；向下拉取 `preventDefault` + 阻尼封顶（`maxPull`，默认 96px）；释放 ≥ 阈值（默认 64px）→ 执行 `onRefresh` 并保持指示器高度直到返回的 Promise 落地（失败静默——`catch` 后照常释放）；回拉超过起点/`touchcancel`/容器中途滚动均中止。
- **`useEdgeSwipeBack`**：左边缘 24px 区（`EDGE_ZONE_PX`）内 pointerdown + 右滑 ≥ 40px（`EDGE_COMMIT_PX`）触发一次 `onBack`；纵向放弃、未达阈值释放/取消不触发。
- **SessionsPage**：行改为「固定操作条（Rename/Delete 各 64px，露出宽 128px）+ 前景行 translateX」结构；两个按钮触发与桌面相同的 `renameSession`/`deleteSession`（复用 RenameSessionDialog/DeleteSessionDialog 确认与错误呈现）；下拉刷新调用新辅助 `refreshSessionList(serverId)`（`src/shells/mobile/refresh.ts`：并行 GET /session + GET /session/status → `applySessionList` + `setStatusMap`，即 `syncAll` 的会话半部；移动端尚无目录/项目 UI）；指示器元素高度跟随 pull（拖拽中无过渡、释放后 0.2s 过渡回弹），刷新期间显示 spinner。
- **ChatPage**：整页 spread 边缘右滑 handlers（事件冒泡到页根，zone 判断读事件自身 clientX）；右滑弹回 `navigation.back()`。
- **消息长按菜单**：MessageList/MessageBubble/MessageActions 新增 `mobile` 标志（ChatPage 恒 true，桌面不传）；MessageActions 在移动形态下给气泡列挂长按 handlers，按住 500ms 在按压位置弹出固定 popover——**触屏子集**（复制文本/复制代码/删除，用户消息才可删除；编辑/查看 diff/分叉/回滚等桌面项不出现）；列上加 `[-webkit-touch-callout:none]` 抑制 iOS 原生 callout；桌面 hover 菜单与右键菜单零回归（无 `mobile` 标志不挂长按）。
- **Sheet pointercancel**（M7-05 review 遗留）：`onPointerDown` 增加 window `pointercancel` 监听；触发时移除 move/up/cancel 监听并 `settle()` 到最近档位、`setDragging(false)`——取消的手势**永不关闭** Sheet（已拖过关闭阈值也不关）；卸载清理同步补充。
- **测试（L2 模拟 touch/pointer）**：L1 手势钩子 29 例（方向锁定、提交/阈值、误触 slop、pointercancel 归位与监听释放、长按定时器取消与卸载清理、PTR 阈值/回拉中止/touchcancel/刷新中忽略新触摸/失败释放、边缘滑动触发与取消、click 守卫吞点击、常量对照）；L2：SessionsPage（左滑露出/小滑动回弹/纵向滑动不动/单行互斥/已露出行点按不导航/拖拽后不导航/Rename 对话框改名/Delete 对话框删除、PTR 触发刷新入 store + 指示器保持与释放、低于阈值不刷新、失败静默）、MobileShell（聊天页边缘右滑弹回、区外不弹）、MessageActions 长按（触屏子集菜单、复制文本、无代码块时复制代码禁用、删除对话框、助手消息删除禁用、位移取消、释放点击吞掉、桌面无长按行为）、Sheet pointercancel（吸附最近档位不关闭、超过关闭阈值取消不关闭、监听释放）。
- **遗留**：真机触控细节（touch-action 与内容滚动共存、系统返回手势与边缘滑动的竞争、PTR 与 iOS 原生回弹叠加）留待 L5 checklist 与 M7-07 触觉反馈；长按触发后快速点击菜单项（500ms 守卫窗口内）可能被 click 守卫吞掉一次（菜单保持打开，再次点击生效）。

## 附录：TASK-M7-05 落地备注（2026-08-05）

**落地内容**

- **Sheet 基础组件**（`src/components/Sheet.tsx`）：props `{ open, onClose, snap?: "low"|"mid"|"high", title?, dismissible?, testId?, children }`。固定 scrim（点击关闭、`aria-hidden`，打开时 0→1 淡入）+ 底部面板（固定 95vh 高、顶部圆角 `var(--r-xl)`、`pb-safe` 安全区）+ 拖动把手。三档吸附按视口高度百分比（low 25% / mid 60% / high 95%）：面板高度固定为高档位 95vh、以 `translateY` 偏移露出对应份额（0 / 35vh / 70vh），**几何在整次手势中不变**，吸附只是纯平移。
- **手势**：handle 与面板上的 pointerdown/move/up（handle 事件冒泡到面板，单一处理链）；拖动期间 `transition: none`（面板 1:1 跟手，不滞后）；松开时——向下超过 ~120px 或快速下甩（速度 > 0.8 px/ms）→ 关闭；其余 → 以 `--ease-spring`（时长 `--dur-med`）吸附到**最近**档位（从三档中取距离最小的，因此上拉可从 mid 升到 high）；拖动结束的 click 守卫：面板作用域 capture 监听器吞掉紧随拖动的 click（防误触面板内按钮），500ms 自移除，绝不跨面板泄漏；window 级 pointer 监听在 pointerup / 卸载时移除。
- **prefers-reduced-motion 降级（双层）**：tokens.css 的媒体查询已将 `--dur-med` 归零（任何 CSS `var()` 消费者自动失效）；JS 侧 `matchMedia` 检查 → 过渡改用 `0ms linear`、打开时跳过 rAF 交接直接到位（jsdom 无 matchMedia，代码做了存在性守卫）。
- **无障碍**：`role="dialog"` + `aria-modal`；打开时焦点移至面板（`preventScroll`）、关闭时还原到打开前的焦点元素（面板可能已先卸载，用打开时捕获的标记而非活元素判断）；Esc 关闭；打开期间 `body` 滚动锁（恢复原值）。
- **`dismissible` 门控**：scrim / Esc / 下滑关闭三个关闭触发器统一受该开关控制——权限/问题卡片必须被回答、不可跳过，接入时固定 `dismissible={false}`（拖动仍可改吸附档位，只是不关闭）；模型选择器保持可关闭。
- **业务接入**：`PermissionSheet.tsx` / `QuestionSheet.tsx` 把卡片主体抽成 `PermissionCard` / `QuestionCard`（桌面 kobalte overlay 与移动 Sheet 共用同一渲染，回复逻辑不重复）；`variant="sheet"` 落地为 `snap="high"` + `dismissible={false}` 的 Sheet，remembered 模式的自动回复效果不再受 variant 门控（两种形态都静默回复）；`ModelPicker.tsx` 抽出 `ModelPickerContent`，移动端（`platform.kind === "mobile"`）用 Sheet 包裹（可关闭、`snap="high"`），桌面保持 kobalte Dialog 零回归（`model-picker` testid 两种形态共用）；`MobileShell` 挂载 `PermissionSheet` + `QuestionSheet`（`variant="sheet"`），桌面 DesktopShell 的 overlay 挂载不动。
