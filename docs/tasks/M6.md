### TASK-M6-01 PTY 服务层与协议验证
- **前置**：M4-01、M1-02 ｜ **模块**：`src/services/pty.ts`、`src-tauri/src/transport/ws.rs`
- **范围**：`pty.ts`、`ws.rs`、协议验证记录
- **API**：`GET,POST /pty`、`GET,PUT,DELETE /pty/{id}`、`GET /pty/{id}/connect`、`POST /pty/{id}/connect-token`、`GET /pty/shells`；事件 `pty.*`
- **规格**：CRUD 封装（REST 走 M1-01 通道）；**WebSocket 数据通道同样下沉 Rust**（`ws.rs`：`pty_ws_connect/send/close` commands，tokio-tungstenite，二进制帧经 Channel 直推 xterm，避免 WebView 直连的 CORS/ATS 问题）；connect-token 获取与 URL 组装在 Rust 侧完成；**联调真实 `opencode serve` 确认 connect 协议并在本文件附录记录**；mock server 补 WS 模拟
- **验收**：真实服务端建连回显成功；mock WS 可用
- **测试**：cargo test（帧编解码）+ L3 + 联调记录
- **提交**：`feat(transport): PTY 服务层与 Rust WebSocket 通道 (TASK-M6-01)`
