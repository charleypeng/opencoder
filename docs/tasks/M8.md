## TASK-M8-05 落地备注

- **模块**：`src-tauri/src/desktop.rs`（桌面专用模块，`#[cfg(desktop)]` 门控——与 single-instance 同一纪律，移动端整个模块不编译）+ `src/services/tray.ts` / `trayBadge.ts`（门面）+ `src/features/settings/desktopPrefs.ts` / `DesktopSection.tsx`（偏好持久化与设置 UI）+ DesktopShell 接线；`Cargo.toml` 增 `tauri-plugin-global-shortcut` 2.3.2 与 tauri `tray-icon` + `image-png` features（`Image::from_bytes` 需 image-png 特性，`tray-icon` 特性开启内置托盘支持，无需第三方插件）。
- **托盘**：`TrayIconBuilder`（内置）构建 `main` 托盘——菜单 Show/Hide / New session / 分隔符 / Quit（`MenuItem::with_id` + `PredefinedMenuItem::separator`，`Menu::with_items`），图标用 `icons/32x32.png`，tooltip "opencoder"；窗口操作全部在 Rust 侧（show/hide/unminimize/set_focus/exit，`show_main_window` 与 single-instance 回调同一路径），**New session 经 `tray-new-session` 事件交给前端**（DesktopShell 复用 ⌘N 同一 handler——托盘菜单与快捷键行为等价）；菜单事件在 `on_menu_event` 内按 `event.id.as_ref()` 匹配，quit 走 `app.exit(0)`（绕过 close-to-tray 拦截，是真实退出路径）。
- **全局唤起**：`app.global_shortcut().on_shortcut("Alt+Space", handler)` 注册默认 ⌥Space（"Option+Space" 是 mac 键盘的同一快捷键别名，global-hotkey 解析大小写不敏感且 OPTION/ALT 归一化）；handler 内 `ShortcutState::Pressed` → 显示+聚焦主窗口 + 发 `global-summon` 事件（前端 no-op——窗口操作 Rust 侧完成）；`set_global_shortcut` 命令：先解析验证（`Shortcut::from_str` + **至少一个修饰键**——裸键会全局劫持正常打字，`is_valid_shortcut` 纯函数），**新键注册成功后才注销旧键**（被 OS 拒绝的快捷键不会砸掉旧设置；同一快捷键 id 幂等短路——"Alt+Space" 与 "Option+Space" 解析为同 id）；`get_global_shortcut` 返回当前值（初始即默认）。
- **关闭到托盘**：`on_window_event` 拦截 `CloseRequested` → flag 开启时 `api.prevent_close()` + hide（仅主窗口）；`set_close_to_tray` / `get_close_to_tray` 命令 + SettingsPage 新增 **Desktop 分区**开关（失败内联报错并保持未开启）；偏好经 localStorage `oc-desktop`（`desktopPrefs.ts`，畸形载荷丢弃）持久化，**DesktopShell 挂载时 `applyDesktopPrefs` 重放**（默认快捷键跳过——Rust 启动时已注册；重启保留）。
- **托盘角标**：`tray_set_badge(count)` → `app.tray_by_id("main")` 后 `set_title`（macOS = 徽标文字；Linux = 部分 DE 支持图标旁文字；Windows = tray-crate 明确不支持、no-op）；`badge_title` 纯函数：0→无、1-9→数字、>9→"9+"；前端 `startTrayBadgeSync`（`createRoot` + createEffect 监听 permission store 全服务器队列总长，`pendingPermissionCount` 纯函数）由 DesktopShell 挂载/卸载，**门面侧门控非正数不调 IPC**——重启后徽标本就不存在（省一次往返），代价是队列清零后徽标保留到下次启动（spec 仅定义 >0 路径；Rust 侧 `set_title(None)` 清除通道留作后续扩展）。
- **三平台托盘差异记录（验收项）**：Linux 托盘需要 StatusNotifier/appindicator 宿主——GNOME 默认无（需 AppIndicator 扩展），KDE Plasma 原生支持；Linux 上**必须设置菜单**图标才可见（tray-icon crate 文档注明）；Linux 的托盘**左键点击事件不受支持**（点击始终弹出菜单，`TrayIconEvent` 不派发）；Linux 的 title 文字是否显示取决于 DE 可视化。Windows 的 `set_title` 无效果（无徽标通道）。macOS 的 title 即 NSStatusItem 徽标文字。全局快捷键注册失败（被其他应用占用 / 权限受限）**不阻塞启动**（eprintln 记录，setup 与命令均为 best-effort）。
- **测试**：Rust 单元 5 例（`badge_title` 三态 + `is_valid_shortcut` 接受/拒绝矩阵，`cargo test`）；前端 L1（tray 门面：outside-Tauri 全 no-op + 各命令 invoke 参数 + `setTrayBadge` 非正数门控 + 两个事件订阅的 unlisten 生命周期；`trayBadge` 纯函数求和 + watcher 挂载即推 0 / 队列变更推送 / dispose 停止；`desktopPrefs` 持久化/畸形丢弃/字段形状校验/`applyDesktopPrefs` 默认跳过与空偏好零调用）+ L2（DesktopSection：Rust 现值加载、开关翻转 + 持久化、切换失败保持关态 + 内联错误、快捷键保存 + 失败内联、空值禁用保存；SettingsPage Desktop 分区切换；DesktopShell：`tray-new-session` 事件创建会话（与 ⌘N 同断言）、`global-summon` 监听注册、badge 随 permission store 同步、挂载重放持久化偏好）。
- **L4 备注**：托盘交互（菜单项、左键/右键行为）、全局快捷键真实按压、关闭到托盘、徽标呈现、Linux 各 DE 行为属壳级 E2E，随 M10 L4 基建（tauri-driver）落地；此处仅 cargo 编译 + Rust 单元 + L2 验证。
- **偏差**：托盘「Show/Hide」项不做动态标签切换（窗口可见性变化无原生通道驱动菜单文本更新，保持静态标签）；关闭到托盘仅作用于主窗口（pet 等后续窗口各管各的）。

## TASK-M8-04 落地备注

- **模块**：`src-tauri/`（插件接线 + 分平台窗口配置 + capability）+ `src/shells/desktop/TitleBar.tsx`（窗口 chrome）+ `App.tsx` 挂载点。
- **分平台窗口配置**：Tauri 2 平台级配置文件（`tauri.macos.conf.json` / `tauri.windows.conf.json` / `tauri.linux.conf.json`）经 json_patch 深合并覆盖基础 `tauri.conf.json`——**数组按 RFC 6902 整体替换**，故每个平台文件都完整重复 window 条目（title/size）；macOS = `decorations: true` + `titleBarStyle: "Overlay"` + `hiddenTitle: true`（原生红绿灯悬浮于我们的 bar 之上，系统自带全屏/缩放行为与红绿灯 hover 效果），Windows/Linux = `decorations: false`（自定义控件）；基础配置不动。
- **拖拽与双击最大化**：`data-tauri-drag-region="deep"` 由 Tauri 注入的 drag 脚本（tauri 2.11.5 `window/scripts/drag.js`）原生处理——mousedown 拖拽（`start_dragging`）、双击最大化（`internal_toggle_maximize`，macOS 走 mouseup 路径、鼠标移动即取消，与系统行为一致）、可点击元素（BUTTON 等）自动阻断拖拽，因此**组件不写任何 dblclick 处理**；L2 的「双击最大化」断言落在属性契约上（脚本不在 jsdom 中）。`internal-toggle-maximize` 在 `core:window:default` 内，`start-dragging` 需显式授予。
- **Capability 增补**：`core:window:allow-start-dragging` / `allow-minimize` / `allow-toggle-maximize` / `allow-close`（isMaximized 与 resize 监听已在 default 集内）。
- **Rust 接线**（`src-tauri/src/lib.rs`）：window-state 插件（`Builder::default()`——尺寸/位置/最大化自动保存与恢复，无需 JS 侧）；single-instance 插件（crate 为 `#![cfg(not(mobile))]`，与 barcode-scanner 镜像，注册须 `#[cfg(desktop)]`；回调对主窗口 `unminimize` + `set_focus`，实现二次启动聚焦）；macOS 窗口玻璃（setup 内 `#[cfg(target_os = "macos")]` 块：`apply_liquid_glass(window, Default::default())` 失败（< macOS 26 返回 UnsupportedPlatformVersion）→ 回退 `apply_vibrancy(window, NSVisualEffectMaterial::Sidebar, None, None)`，两调用均吞错不阻塞启动）。
- **TitleBar 组件**：mac 模式 = 左侧 78px 红绿灯避让区（`pl-[78px]`）+ 无自定义按钮（`data-window-controls="mac"`）；win/linux 模式 = 右侧 46px 宽 min/max/close 按钮（`data-window-controls="custom"`，close hover 红色），经 `getCurrentWindow()` 调用 `minimize`/`toggleMaximize`/`close`，`isMaximized` 初始查询 + `onResized` 监听维护最大化/还原图标（窗口状态插件恢复最大化、Win+↑、snap 等外部变更也跟得上），卸载清理监听；非 Tauri（web 构建/L2 环境）渲染纯 inert bar（无控件、不触碰 window API，`isTauri()` 守卫）。
- **挂载点（与计划的偏差）**：TitleBar 挂在 **App 层**（desktop 时在内容上方全宽渲染），而非 DesktopShell 内——窗口 chrome 必须覆盖 ServerHome 首页（Win/Linux 无边框窗口在首页无拖拽区将无法移动窗口，违反「三平台窗口行为原生一致」验收）；DesktopShell 根 `h-screen` → `h-full`、ServerHome 根 `min-h-dvh` → `min-h-full` 适配剩余高度。
- **L4 备注**：壳级 E2E（拖拽/双击最大化、窗口状态跨重启持久化、二次启动聚焦、玻璃材质视觉）随 M10 L4 基建（tauri-driver）落地，此处仅 L2（TitleBar 组件契约 + App 挂载）+ cargo 编译验证。
- **Backlog**：Windows 11 snap layout 悬停预览（最大化按钮 hover 弹布局网格）需自绘实现，原生贴边 snap 仍可用（拖动窗口到边缘触发）；M8-05 托盘可补充「关闭到托盘」对 close 按钮行为的改写。

## TASK-M8-03 落地备注

- **模块**：`src/components/ContextMenu.tsx`（复用菜单组件）+ 四处业务接入（SessionList / MessageActions / FileTree / DesktopShell 选中文本菜单）。

- **子菜单占位**：会话菜单「Move to server」子菜单含置灰「Not available」项（跨服务器迁移是 ui-design §3.2 拖拽 backlog 项）。

- **选中文本菜单**：Shell window 级 contextmenu 监听（最后冒泡到，`defaultPrevented` 放行检查使消息/文件/会话菜单优先），非空选中 → Copy / Quote in chat（`quoteBlock` 把每行前缀 `> ` 进 composer 预填）。
