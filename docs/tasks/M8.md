## TASK-M8-02 落地备注

- **模块**：`src/shells/desktop/CommandPalette.tsx`（对话框）+ `src/shells/desktop/paletteItems.ts`（纯结果构建，L1 直接钉）。
- **六个来源**：会话（session store，按 title/slug 本地过滤，store 顺序即最近优先）、文件/符号（复用 `/find/file` + `/find/symbol` 与 QuickOpen 相同的 150ms 防抖 + 序号防陈旧；`#` 前缀进入符号模式）、命令（GET /command 每个组件实例取一次并跨开关缓存，失败下次重试；经 `POST /session/{id}/command` 在活动会话运行，与斜杠菜单同通道）、设置（静态动作：新会话/设置/侧栏/终端/diff；主题切换属 M9-03，刻意缺席）、服务器（注册表列表，切换 = rail 点击同款 `setActiveServer`）。
- **无活动会话门控**：Commands 段与 diff 动作均需活动会话（`hasActiveSession` prop 由 DesktopShell 传入），避免空会话下死条目。
- **执行模型**：文件/符号沿用 QuickOpen 副作用（viewer tab + activeLine + 每服务器 recent 记忆），其余经 `actions` prop 回调；回调与 ⌘ 快捷键同一批 handler（新会话走 fork-error banner，命令失败走 toast）。
- **键盘**：↑↓ 跨段换行（flat 行列表 + 每段 offset），选中值 clamp（本地过滤可中途收缩列表），Enter/点击执行并关闭，Esc 仅关闭。
- **陷阱记录**：打开 effect 若同步调用命令目录守卫（其读取 `commands()` 信号）会让 effect 追踪该信号——目录落地时 effect 重跑并重置查询；用 `untrack` 包住取数调用解决。
- **冲突**：⌘K 与 ⌘P 各开各的对话框（shell 测试断言两者互不串扰）；⌘K 的 inputGuard 保持默认（输入框聚焦时不触发）。

## TASK-M8-01 落地备注

- **注册中心**：`src/features/settings/shortcuts.ts`（纯核心）+ `shortcutStore.ts`（localStorage `oc-shortcuts` 持久化）+ `useShortcuts.ts`（派发 hook）+ `ShortcutsSection.tsx`（设置 UI）。
- **主修饰键语义**：Combo 的 `ctrl` 字段 = 主修饰键（⌘/Ctrl），捕获时归一化；派发时 **⌘ 或 Ctrl 任一命中**（webview 务实选择，与迁移前测试兼容）；`meta` 字段仅非 mac 平台显式 Super 键，默认表未使用。
- **默认表**：ui-design §3.3 全量 15 项；`switchServer` 的键为区间 `1..9`（与任意数字键重叠，冲突检测感知区间）。
- **接线**：DesktopShell 注册 quickOpen/fullTextSearch/sessionDiff/toggleTerminal/newSession/switchServer/prevSession/nextSession/toggleSidebar/openSettings；⌘K 由 M8-02 接线；⌘Enter/Tab/↑/Esc 为输入本地行为，留在 PromptBox/sheets（注册表列出、壳不注册，文件头已文档化）。
- **作用域**：`activeScope` 由 DesktopShell 按聚焦区设置（chat=composer、list=会话列表、其余 global），经根节点 `data-active-scope` 暴露；默认表中仅 sendMessage 为 chat 作用域且未被注册——list 作用域机制已实现并有测试，暂无默认项使用（M8-02 可占用）。
- **冲突**：自定义 combo 与任一其他项（含未注册项）修饰键+键重叠即拒绝保存并内联警告（列出冲突项名称与 combo）。
- **已知边界**：捕获期间被按下的键经 capture 阶段 stopImmediatePropagation 阻断，不会触发全局派发；Esc 在捕获中用于取消（不会保存）。
