# M2 — 会话核心 MVP

> 出口标准：项目/目录切换可用；会话 CRUD；发送 prompt 并流式渲染 text/reasoning/tool 三类 Part；可中断。

---

### TASK-M2-01 领域服务层：project/session/message
- **前置**：M1-01 ｜ **模块**：`src/services/`
- **范围**：`src/services/project.ts`、`session.ts`、`message.ts`
- **API**：`/project`、`/project/current`、`/path`、`/session`（GET/POST）、`/session/{id}`（GET/PATCH/DELETE）、`/session/status`、`/session/{id}/message`（GET）、`/session/{id}/prompt_async`、`/session/{id}/abort`
- **规格**：按架构 §4.4 形态封装；分页参数（`limit`/`before`）；错误透传 ApiError
- **验收**：对 mock 全方法契约通过
- **测试**：L3 契约（每端点 ≥1）
- **提交**：`feat(api): project/session/message 服务层 (TASK-M2-01)`

### TASK-M2-04 会话列表

### TASK-M2-05 会话创建/改名/删除
- **前置**：M2-04 ｜ **模块**：`src/features/sessions/`
- **范围**：新建按钮、改名对话框、删除确认

- **规格**：新建即进入空会话；改名 Enter 提交/Esc 取消；删除二次确认（Sheet/对话框）；全部乐观更新 + 失败回滚
- **验收**：三类操作 E2E 通过（E07）
- **测试**：L2 + E2E E07
- **提交**：`feat(sessions): 会话创建/改名/删除 (TASK-M2-05)`

### TASK-M2-08 输入框与发送（prompt_async）
- **前置**：M2-06 ｜ **模块**：`src/features/sessions/PromptBox.tsx`
- **范围**：PromptBox、附件按钮（占位，M3 接线）
- **API**：`POST /session/{id}/prompt_async`
- **规格**：自适应高度 textarea；⌘/Ctrl+Enter 发送；空输入 ↑ 召回上条 prompt；发送后立即清空+本地插入用户消息（乐观）；生成中输入框置 loading 态；`Esc` 触发 abort（M2-09）
- **验收**：mock happy-chat 全链路 E2E（E03）
- **测试**：L2 + E2E E03
- **提交**：`feat(sessions): 消息输入与异步发送 (TASK-M2-08)`

### TASK-M2-09 流式渲染管线
- **前置**：M2-08、M2-02 ｜ **模块**：`src/features/messages/`、`src/stores/messages.ts`
- **范围**：delta 应用逻辑、打字光标组件
- **API**：事件 `message.part.updated/delta`
- **规格**：delta 追加 O(1)；呼吸光标；生成中顶部细进度条；长消息虚拟列表（@tanstack/virtual 或手写）；性能：1000 parts 60fps（性能测试用例）
- **验收**：逐 token 上屏 < 50ms；虚拟滚动无卡顿
- **测试**：L1（delta 合并）+ 性能基准
- **提交**：`feat(messages): 流式增量渲染管线 (TASK-M2-09)`

### TASK-M2-10 中断与错误态
- **前置**：M2-08 ｜ **模块**：`src/features/sessions/`、stores
- **范围**：停止按钮、错误横幅、重试按钮
- **API**：`POST /session/{id}/abort`、事件 `session.error`、`session.status`
- **规格**：生成中显示停止按钮（Esc 同效）；`session.error` 横幅（可关闭、含错误详情展开）；Provider 限流/网络错误分类文案；空闲后自动恢复输入
- **验收**：E2E E04；错误 fixture 展示正确
- **测试**：L2 + E2E E04
- **提交**：`feat(sessions): 中断生成与错误处理 (TASK-M2-10)`
